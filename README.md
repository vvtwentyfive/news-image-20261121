A one-page newspaper front page summing up the world's news of Saturday 21 November 2026: 44 stories across 7 regions, with 3 hero stories and 10 illustrated grid stories, a day-in-numbers strip, a region bar, a numbered index of 31 more stories, a dotted world map with pins, and a boxed DATE CHECK naming what was deliberately left out because it was not Saturday's news. Every picture is an original drawing rendered in code; all text is rendered in code too.

## Run it

```sh
python3 main.py
```

This copies `entry.png` to `/output/entry.png` (or to `$MAKEFUN_OUTPUT_DIR/entry.png` when that variable is set).
